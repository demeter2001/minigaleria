# Mini Galería (prototipo 0.1)
## Opción A: Android Studio
Abre la carpeta, deja que sincronice y pulsa Build > Build APK(s).
## Opción B: sin instalar nada (GitHub)
1. Crea un repositorio en github.com y sube todo el contenido de esta carpeta.
2. Pestaña Actions > Build APK > se ejecuta solo (o "Run workflow").
3. Descarga el artefacto MiniGaleria-apk (zip con el .apk) e instálalo en tu teléfono.
